Enterprise GenAI platform · employer-owned

DAS Author

Python · FastAPI · LangGraph · LLM Agents · RAG · ChromaDB · Azure PostgreSQL (pgvector) · MongoDB Atlas · OCR · Docker · Azure App Service
  • Days down to minutes. Production time per deliverable, before → after: narrated video 4–5 days → 40 min; SCORM training 1.5 days → 5 min; slide deck 1 day → 15 min; infographic 3–4 hrs → 2 min.
  • One upload, nine formats. The full pipeline — ingestion, chunking, pgvector search on Azure PostgreSQL, LangGraph orchestration and format-specific renderers — producing 9 output types (slide deck, SCORM, narrated video, PDF, infographic and more) from one mixed-modality upload.
  • Source fidelity. A deterministic layer that enforces section coverage, verbatim quoting of source data and automatic removal of unstated detail, so generated content stays anchored to the source rather than invented.
  • Screenshot annotation engine. OCR-driven detection of UI elements in application screenshots, with automatically generated numbered callouts and instructional captions. OCR libraries benchmarked for CPU speed.
  • Human in the loop, nothing lost. A plan-approval gate with an editable document round-trip, plus checkpoint-based resume so interrupted long-running generation jobs are never lost or re-paid for.
  • Built end to end. Architected, built and deployed to production on Azure App Service using AI-assisted development with Claude Code.
Built at Sastrageek Solutions — the platform, its code and its content belong to the company. This page covers my role, the stack and measured outcomes only: no source code, prompts, client names, client data, screenshots or internal links.
